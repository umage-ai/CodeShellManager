## Design history

These were written before or while the features were built. Each starts with a status note that
says what is current and points to the user documents above. They explain why things are the way
they are; they do not describe how the app works today.

| Document | What's in it |
|---|---|
| [plan.md](plan.md) | The 2.0 rewrite: architecture, crate layers, design decisions and their reasons. Its crate and layer table is current. |
| [phase0-spike.md](phase0-spike.md) | The terminal-rendering spike that decided the stack |
| [design/keyboard.md](design/keyboard.md) | Design of the keyboard navigation and the rebindable keymap (current behaviour: [keyboard.md](keyboard.md)) |
| [design/remote-csm.md](design/remote-csm.md) | Research and build log for CSM-to-CSM remote access, the peer link and the relay path (current behaviour: [remote-access.md](remote-access.md)) |
| [wpf/](wpf/) | The 0.x WPF app: its README, its comparison, and `lessons.md`, the record of hard-won behaviour (ConPTY, git, quoting, restart and shutdown races) that 2.0 carries over |
